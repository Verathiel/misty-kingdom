# Misty Kingdom — Kaňon a mosty

Godot 4 project with a painted canyon map and a large buildable plateau.

## Open
1. Extract this folder.
2. In Godot 4.7, choose **Import** and select `project.godot`.
3. Open the project and press **F6** to run the main scene.

## Controls
- **PC:** left click places a selected building; mouse wheel zooms toward the cursor; hold the right or middle mouse button and drag to pan.
- **Mobile/tablet:** tap to place; drag with one finger to pan; pinch with two fingers to zoom.
- Use **+ / −** to zoom and **Vycentrovat mapu** to reset the view.
- On narrow screens, use **☰ Stavění** to show or hide the building panel.
- Save/load stores placed buildings locally.

The buildable area has been expanded across most of the central plateau. The landscape is a painted background; placed buildings are currently lightweight drawn prototypes, not final detailed art assets.
